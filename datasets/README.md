# Dataset directory policy

This directory intentionally contains policy text only. No audio corpus or dataset is included. Do not add recordings, restricted dataset archives, private protocols, credentials, or derived speaker artifacts to Git. Any future dataset use requires documented terms, rights/consent, ethics/privacy review, access controls, and retention/deletion rules; see [`docs/DATASETS.md`](../docs/DATASETS.md). Phase 2 does not download datasets or train models.
